# 이분탐색 Binary Search
문제의 크기를 절반으로 줄이면서 빠르게 답을 찾는 알고리즘
시간복잡도: O(logn)
주로 반복문으로 구현
** 배열이 정렬되어야 성립

동작 원리
    left, mid, right 세 포인터를 이용해 탐색 범위를 절반씩 좁혀감

BST와의 관계
    이분 탐색의 대상 원소들을 트리 구조에 넣으면 이진 탐색 트리(BST)
    BST 조건: key(왼쪽 서브트리) < key(루트) < key(오른쪽 서브트리)
    BST를 중위 순회하면 정렬된 배열이 나옴

Lower Bound / Upper Bound
    중복 원소가 있을 때 특정 값의 범위를 찾는 기법
    Lower Bound: x 이상의 수가 처음으로 나오는 위치
    Upper Bound: x를 초과하는 수가 처음으로 나오는 위치

Parametric Search
    최적화 문제를 결정 문제로 변환하여 이분 탐색을 적용하는 기법
적용 조건
    가능한 답의 나열이 비내림차순 또는 비오름차순이어야 함
    문제에서 최댓값/최솟값을 요구한다면 Parametric Search를 의심
풀이 흐름
    최적화 문제를 결정 문제로 변환 ("x일 때 가능한가?")
    가능한 x의 범위에 이분 탐색 적용
    조건을 만족하는 X의 최댓값(또는 최솟값)이 정답

정리
    정렬된 배열에서 특정 원소 탐색 시 이분 탐색(O(logn))보다 빠른 방법은 없음
    분할 정복과 달리 답이 없는 절반을 버림
    최댓값, 최솟값 키워드가 보이면 이분 탐색(Parametric Search)을 먼저 의심
    효율성 테스트 문제에서 자주 출제됨
